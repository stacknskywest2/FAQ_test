# v16.2.0_패키지

## 작업 기준
- 기준 버전: v16.1.5
- 생성 버전: v16.2.0
- 작업 성격: 홈 화면 UI 밀도 조정 및 메뉴 배치 변경

## 반영 사항
- 홈 화면 메뉴 배치를 아래 순서로 재정렬했습니다.
  1. 검색창
  2. 업무분야로 보기
  3. 빠른 해결
  4. 처음 이용한다면
  5. 업무편람 e-book
- 기존 "많이 찾는 업무" 영역을 삭제했습니다.
- 업무분야·빠른 해결·처음 이용한다면·업무편람 e-book 버튼 높이를 "사용방법 보기" 버튼 수준으로 축소했습니다.
- 빠른 해결 카드의 아이콘·보조설명을 홈 화면에서는 숨겨 버튼형 밀도를 높였습니다.
- 업무편람 e-book 영역은 홈 화면에서는 컴팩트 버튼형으로 표시되도록 조정했습니다.
- v16.1.5의 인트로 및 업무편람 자산은 유지했습니다.
- service-worker 캐시 버전을 v16.2.0으로 갱신했습니다.
