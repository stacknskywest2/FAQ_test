뚜미 FAQ v15.6.2.2 HTML 패키지

/goal: 사용자가 원하는 질문에 도달할 수 있는가

- v15.6.2.2는 v15.6.2.1을 기준으로 한 UI 전용 패치 버전입니다.
- 홈 화면의 최상위 4개 카테고리 버튼을 하나의 안내 박스 안에 2행 2열로 재배치했습니다.
- 박스 제목은 “큰 카테고리별 질문트리”로 표시하여 사용자가 업무 분야를 먼저 고른 뒤 하위 질문트리로 진입하는 구조를 바로 이해할 수 있게 했습니다.
- 카테고리 질문트리 박스를 홈 화면 검색창 바로 아래에 먼저 배치하여 첫 화면에서 질문트리 진입 영역이 바로 보이도록 했습니다.
- 각 카테고리 버튼에는 A/B/C/D 코드와 짧은 업무 힌트를 함께 표시했습니다.
- FAQ 답변 문구, 카테고리 데이터, 검색 로직, 법령조회, e-book, 앱 저장 안내, PWA 기능은 변경하지 않았습니다.
