# v16.2.1_패키지

## 1. 작업 기준
- 기준 버전: v16.2.0
- 생성 버전: v16.2.1
- 작업 성격: 홈 화면 보조 메뉴 구성 변경 + 모바일 다크모드 화면 보정

## 2. 반영 사항
1. "처음 이용한다면" 영역의 버튼명을 변경했습니다.
   - 기존: 사용방법 보기
   - 변경: 챗봇 사용방법

2. "업무편람 목록보기" 버튼을 삭제했습니다.

3. "앱으로 저장하기" 버튼을 새로 만들었습니다.
   - 홈 화면의 "처음 이용한다면" 영역에서 바로 접근할 수 있습니다.
   - 기존 사용방법 안내 안에 있던 앱 저장 방법을 별도 화면으로 분리했습니다.

4. "챗봇 사용방법" 화면에서는 FAQ를 찾는 방법만 안내하도록 정리했습니다.
   - 검색창 이용
   - 빠른 해결 카드 이용
   - 업무분야 버튼 이용
   - 업무편람 e-book 접근
   - 업데이트 안내 확인

5. 모바일 다크모드 표시를 보정했습니다.
   - 배경, 카드, 버튼, 검색창, 안내문, 답변 말풍선, 법령 팝업, 업데이트 팝업, 사용방법 화면의 색상을 다크모드 전용 팔레트로 조정했습니다.
   - 라이트모드 화면 구성과 기능은 유지했습니다.

6. 버전 관련 파일을 v16.2.1 기준으로 갱신했습니다.
   - index.html
   - version.json
   - manifest.webmanifest
   - service-worker.js
   - README.txt

## 3. 배포 전 확인 권장사항
- 모바일 라이트모드에서 홈 화면 버튼 배열 확인
- 모바일 다크모드에서 검색창, 버튼, 말풍선, 안내문 가독성 확인
- "챗봇 사용방법" 버튼 클릭 시 앱 저장 안내가 빠져 있는지 확인
- "앱으로 저장하기" 버튼 클릭 시 Android/iPhone 저장 방법이 나오는지 확인
- GitHub Pages 배포 후 기존 캐시가 남아 있으면 새로고침 또는 업데이트 버튼으로 최신본 적용

## 4. 변경 범위
- FAQ 문항 DB 내용은 변경하지 않았습니다.
- 업무편람 PDF, 법령 PDF, 답변 이미지 파일은 변경하지 않았습니다.
- 화면 UI, 안내문, 다크모드 CSS, 버전 파일만 수정했습니다.
