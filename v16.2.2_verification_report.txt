v16.2.2 검증보고서

1. 작업 기준
- 기준 버전: v16.2.1
- 생성 버전: v16.2.2
- 작업 요청: 업무편람 e-book UI에서 표지 이미지를 다시 보이게 하고, 홈 화면 e-book 버튼명에서 "업무편람" 문구를 삭제

2. 반영 결과
- 홈 화면 업무편람 e-book 카드의 표지 이미지 노출을 복원함
- 홈 화면 e-book 카드 버튼 표시명에서 "업무편람" 문구를 제거함
  · 굴뚝 원격감시체계 업무편람 → 굴뚝 원격감시체계
  · 사업장 대기오염물질 총량관리제도 업무편람 → 사업장 대기오염물질 총량관리제도
- e-book 카드 선택 시 기존 openManualViewer 동작을 유지함
- PDF 다운로드 버튼은 홈 화면에서 숨김 상태를 유지하여 첫 화면 밀도를 과도하게 늘리지 않음
- 다크모드에서도 표지 카드 배경과 경계선이 자연스럽게 보이도록 CSS를 보정함

3. 변경 파일
- index.html
- version.json
- manifest.webmanifest
- service-worker.js
- README.txt

- 모바일 라이트모드에서 업무편람 e-book 표지가 보이는지 확인
- 모바일 다크모드에서 표지 카드 배경과 글자 대비 확인

- 각 e-book 카드 선택 시 기존처럼 뷰어가 정상 열리는지 확인
