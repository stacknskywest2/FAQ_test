v16.2.1 검증보고서

1. 작업 기준
- 기준 버전: v16.2.0
- 생성 버전: v16.2.1
- 작업 범위: 처음 이용한다면 메뉴 구성 변경, 앱 저장 안내 분리, 모바일 다크모드 CSS 보정, 버전 파일 갱신

2. 반영 내역
- "사용방법 보기" 버튼명을 "챗봇 사용방법"으로 변경
- "업무편람 목록보기" 버튼 삭제
- "앱으로 저장하기" 버튼 생성
- 기존 사용방법 안내에 포함되어 있던 앱 저장 방법을 별도 "앱으로 저장하기" 화면으로 분리
- "챗봇 사용방법" 화면은 FAQ 탐색 방법 중심으로 정리
- prefers-color-scheme: dark 기반 다크모드 전용 CSS 오버라이드 추가
- 모바일 다크모드에서 배경, 헤더, 카드, 버튼, 검색창, 안내문, 답변 말풍선, 법령 팝업, 업데이트 팝업 색상 보정
- theme-color 동기화 스크립트 추가
- manifest.webmanifest, version.json, service-worker.js, README.txt 버전 갱신

4. 수동 확인 필요 사항
- 모바일 실제 기기에서 라이트모드 홈 화면 확인
- 모바일 실제 기기에서 다크모드 홈 화면 확인
- "챗봇 사용방법" 버튼 클릭 시 앱 저장 방법이 분리되어 있는지 확인
- "앱으로 저장하기" 버튼 클릭 시 Android/iPhone 저장 안내가 정상 표시되는지 확인
- GitHub Pages 배포 후 기존 캐시가 남아 있으면 업데이트 버튼 또는 강제 새로고침으로 최신본 적용
