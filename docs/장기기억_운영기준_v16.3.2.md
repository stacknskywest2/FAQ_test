# COP_FAQ 장기 운영기준 v16.3.2

## 장기기억 적용사항

1. 최신 운영 기준 버전은 v16.3.2이다.
2. v16.3.2의 핵심은 기능 추가가 아니라 Google Apps Script·Google Sheets 계정 변경 대응형 운영 유연화이다.
3. Apps Script Web App URL은 `index.html`에 고정하지 않고 `feedback-config.json`에서 관리한다.
4. 담당자 또는 운영계정 변경 시 새 Web App URL을 발급한 뒤 `feedback-config.json`의 `primary_endpoint`만 교체하는 것을 기본 절차로 한다.
5. 가능하면 `stacknsky_west2@keco.or.kr`를 운영계정과 보고서 수신계정으로 유지한다.
6. 설치형 트리거는 생성 계정에 귀속되므로 계정 변경 시 새 운영계정에서 `installTriggersNow`를 다시 실행해야 한다.
7. 사용량 실적관리는 자동 수집한다. 의견 보내기는 자발적 개선 의견 접수 기능이며, 기본 사용량 로그 저장 조건이 아니다.
8. 자동 수집 대상은 PAGE_VIEW, HOME_OPEN, MENU_OPEN, FAQ_OPEN, SEARCH_SUCCESS, SEARCH_FAIL, EBOOK_OPEN, EBOOK_SEARCH_SUCCESS, EBOOK_SEARCH_FAIL, FEEDBACK_CLICK 등 비식별 이벤트로 제한한다.
9. 이름, 연락처, 사번, IP, 위치정보, 기기 고유정보, Google 계정 정보, 브라우저 fingerprint는 수집하지 않는다.
10. Google Sheets 통계 수식 오류와 Apps Script 수신 장애는 분리해서 판단한다. `사용량원본` 또는 `응답원본`에 행이 쌓이면 수신창구는 정상이다.
11. 배포 전에는 FAQ 배포 전 10대 보안점검표 v1.1 기준을 계속 적용한다.
12. 패키지 제출 시 README, version.json, manifest.webmanifest, service-worker.js, 검증보고서를 버전명과 일치시킨다.
